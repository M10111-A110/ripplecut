## Known limits of this validation

* The validator is independent of the solvers but shares the single engine by design (master spec §97-§99). Engine correctness is covered by hand-calculated and property tests, not by the validator.
* Uncertifiable infeasibility is accepted only from a completed exact search, labeled 'not independently certified' (tests/test_validator.py::test_uncertifiable_infeasibility_needs_complete_exact_search).
* All results concern the explicit model; none validates real Online Boutique behavior.
